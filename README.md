# Cross-Language Performance Disparity Dataset

This repository contains the synthetic acoustic-feature dataset used in the pilot study for evaluating cross-language performance in speech-based depression detection.

## Dataset

- 240 samples
- 120 English samples
- 120 Malayalam samples
- 10 numerical acoustic features
- Language information
- Depression class labels
- Train/test split information

The dataset contains synthetic numerical acoustic features and does not contain raw speech recordings.

## Purpose

The dataset was used to demonstrate the downstream classification and cross-language evaluation pipeline.

## Note

This is a synthetic dataset and should not be interpreted as a clinical speech dataset or as evidence of real-world depression-detection performance or cross-language fairness.
